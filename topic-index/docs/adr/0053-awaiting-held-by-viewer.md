# 0053 返事待ちは、本人が持っているトピックに絞る

- 状態: 採用（2026-11-28）
- 関連: 0038（担当とアテンション。相手待ちの見え方を本人の目線で絞る）、0052（今やることの区分）

## 背景

0038 の相手待ちは、トピックごとに 1 つに決まる見え方だった（こちらから送ったシグナルで名指しした、読者でない相手の名指しが残っている）。「こちら」は読者全員なので、共有リストでは次のものまで本人の返事待ちに出ていた。

- 課題を起票した直後のもの。担当が読者でない人（社外の協力者など）なので、起票のシグナルの名指しが相手待ちになる。本人は担当でなく、返事を待つ立場でもない
- 共有メールボックスで、ほかのメンバーが送って担当のまだいないもの

返事待ちは「自分が返事を待っているもの」の一覧として使われるので、本人が持っていないものは要らない。

## 決定

1. 一覧と詳細の `awaiting`（と `filter=awaiting`）は、Viewer が持っているトピックの相手待ちだけにする。持っているとは、個人リストのもの（持ち主は本人）か、担当（0038 の決定 1）に Viewer がいるもの（`holdsThread`・`isAwaitingFor`）
2. 担当のいない共有のトピックは、返事待ちに出さず割当待ちで見る
3. トピックごとの相手待ち（`isAwaiting`）は残す。取り込みの区切り（`awaitingThread`）、結んだ先の様子（`derivedBall`）、参照専用の管理画面はそちらを使う

## 結果

- 今やることの返事待ちの件数が、本人の送ったものと担当のものに減る
- 担当のいない共有のトピックで相手を待っているものは、誰かが担当するまで割当待ちに出る
