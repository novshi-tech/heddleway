# 0052 「今やること」をスマホの 1 画面に収めるファーストビューと、区分ごとの画面にする

- 状態: 提案（2026-11-26）。実装は同じ PR に入れた（末尾の「実装の記録」）
- 関連: 0051（今やることの画面。この ADR で決定 2 を置き換える）、0038（担当とアテンション）、0039（個人リストと共有リスト）、0047（一覧の範囲）

## 背景

0051 の画面は、見えるリストの開いているトピックを区分ごとに全部並べた（1 区分 15 件を超えた分は「ほか n 件」に畳む）。使ってみて次のことが分かった。

- 毎日何度も開く画面なのに、情報量が多い。あるデプロイでは開いているトピックが 1 人あたり 500 件近くあり、畳んだ区分の中身まで毎回 HTML にして送っていた
- アテンションを全件フラットに並べても読めない。割当待ちも 100 件近くになる
- 「ほか n 件」が、行の相手の人数（「田中、佐藤 ほか 3」）と区分の残りの件数の 2 か所にあり、何にかかっているのか分かりにくい
- 使ってほしいのは事務所の外にいる人も含むので、スマホで開いてすぐ分かることを先にする（PC の画面はあとで、スマホの形を崩さずに広げる）

## 決定（案）

### 1. ファーストビューはスマホの 1 画面に収まるものだけにする

上から次の順に出す。

1. 期限切れ・今日までの数（自分がやるもののうち）。押すと自分がやるものの画面へ
2. 自分がやるもの: 担当（0038）と、個人リストの To Do・Google Tasks の開いているタスクを 1 つにまとめ、期限の近い順に上位 5 件。超えた分は「n 件すべて見る」で区分の画面へ
3. アテンション: トピックは並べず、リストごとの件数だけ（本人宛ての数を添える）。新しく動いたリストが上。押すとそのリストのアテンションの画面へ
4. 返事待ち・割当待ち: 件数だけの 1 行（返事待ちは期限切れの数を添える）。割当待ちは 0 件なら出さない

区分の分け方（1 つのトピックは最初に当てはまる区分にだけ出す）は 0051 と同じで、担当とタスクを 1 つにしたことだけが違う。

### 2. 区分ごとの画面を足す

`/mine`（自分がやるもの）、`/attention`（リストごとの見出しで全部）と `/attention/<リストの ID>`（1 つのリスト。本人宛てが先、新しい順）、`/awaiting`（返事待ち）、`/triage`（割当待ち）。どれも同じ形の一覧で、上に「← 今やること」を置く。メンバーでないリストの ID は 404（0048 と同じく、あることを分からせない）。

### 3. 一覧の行は件名・期限・「いつ・どのリスト・状態」だけ

相手の名前は一覧から外し、トピックの詳細にだけ出す。「ほか」は区分の残りにも使わず、「n 件すべて見る」と書く。

### 4. 今やることと区分の画面は接続の状態を読まない（と、一覧の結び候補を逆引きで出す）

リストの種類（Jira かタスクのリストか）はデータソースの出所で決まるので、参加中のリストの画面だけが接続の一覧（取り込みの状態）を読む。

あるデプロイの実測では、開くたびのサーバーの CPU が 0.2〜0.5 秒で、送る HTML を小さくしても変わらなかった。一覧（`listThreads`）がスレッドごとに結び候補を全スレッドとの総当たりで探していて、件数の 2 乗で増えていた。一覧では、キー → スレッドの逆引き（`candidateIndex`）を 1 回だけ作って引く。返す候補は総当たりと同じ（API の一覧も同じく速くなる）。画面は結び候補を出さないので、一覧の範囲（0047）を結び候補のキーなしで読む（`ListScopeRequest.candidates: false`。キーの索引と、キーを共有するスレッドを読まない）。ゲートウェイは同意の確かめと本文の材料を並べて待つ。

## 考えたほかの案

- **区分を畳んだまま全部を 1 ページに置く（0051 のまま件数を絞る）**: 畳んだ中身も毎回作って送るので重さが変わらない。開いたときに取りに行く形にするなら、区分を別の画面にするのと同じになる
- **アテンションを相手ごとにまとめる**: どこから来たか（チャネル・メールボックス・Jira のプロジェクト）が分かるリストごとのほうが、件数も安定する

## 残ること

- 画面を PWA にする（前回の内容をすぐ出して裏で最新にする。ホーム画面に置ける）。そのための画面用の軽い JSON の口（ブラウザのセッションで呼ぶ）
- 今やることを Heddleway のトップにする（リストのメンバーの人だけ）
- 0051 の残り（操作を置くか、ソースへのリンク、自動の更新）
