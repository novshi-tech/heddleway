# 0055 LINE のトピックから、受け口の会話の画面を開く

- 状態: 採用（2026-11-28）
- 関連: 0049（LINE 公式アカウント）、0051（トピックの詳細の画面）、0054（中身は元のアプリへのリンクで開く）

## 背景

0054 で、画像や添付の中身はトピック索引で持たず、元のアプリへのリンクで開くと決めた。LINE は元のアプリ（公式アカウントの管理アプリ）に会話ごとの URL がなく、そこから返した分は受け口の Webhook に流れず原本に残らない。受け口（業務システム）が、会話を読み、画像を見て、返信を送れる会話の画面を持った。

## 決定

1. LINE のリストのトピックの詳細に「LINE のトークを開く」リンクを出す。行き先は受け口の会話の画面（`/line/<conversationId>`）。会話はそのトピックのメッセージのアンカー（0049 の `conversationId`。1 対 1 なら相手の userId、グループ・トークルームならその ID）
2. 行き先の URL は LINE のコネクタ（受け口を読む口と同じ場所）が持つ。コネクタは受け口の固定のクエリを読む前提なので、画面も同じ受け口のものにする
3. Jira の課題へのリンク（0051）と同じ位置・同じ見た目に出す。トピック索引からは送らない（送信は受け口の画面かエージェント。0049 のまま）

## 結果

- 経過で画像やファイルのあるメッセージを見たら、会話の画面で中身を見て、その場で返せる
- 返信を受け口の画面から送れば原本に Outbound として残り、トピックの経過にも上がる
