# 0011 リストのメンバーには「今やること」を Heddleway のトップにし、接続の管理は /connections に移す

- 状態: 提案(2026-11-26)。実装は同じ PR に入れた
- 関連: [0010](0010-pages-as-an-installable-app.md)(ホーム画面に置けるアプリ)、トピック索引の [`0052`](../../topic-index/docs/adr/0052-now-first-view.md)(今やることのファーストビュー)

## 背景

Heddleway のトップ(`/`)は「つないだサービス」(接続・機能・許可したアプリの管理)だった。毎日開くのはトピック索引の「今やること」で、管理の画面は最初の設定とたまの手直しでしか開かない。毎日開くものがトップにあるべき。

## 決定(案)

1. **機能が本人のトップになるかを決める。** `Feature.userPage.isHome(userId)` を足す。トピック索引は、本人がどれかのリストのメンバーなら true(User は作らない)
2. **`/` はトップを振り分ける。** サインインした本人について、トップになる機能があればその画面(`/features/<name>`)へ 303 で送る。なければ今までどおり「つないだサービス」を出す。機能の判断が失敗したときも「つないだサービス」を出す
3. **「つないだサービス」は `/connections` にも置く。** 画面の上のメニューに「つないだサービス」を足し、各画面の「つないだサービスに戻る」、接続・削除・ペアリング・取り消しのあとの戻り先(`/connections?added=...` など)、エージェントに返す登録・つなぎ直しの案内(`register_url` など)を `/connections` にする
4. 今やることの画面から「← つないだサービス」を外す(トップなので戻る先ではない)

## 考えたほかの案

- **`/` で今やることをそのまま描く(リダイレクトしない)**: アドレスが 2 つになり、Service Worker の写し(0010)が `/features/...` だけなので、トップを開いたときに写しが効かない
- **全員のトップを今やることにする**: リストに入っていない人(トピック索引を使っていない人、トピック索引のないデプロイ)には空の画面になる。最初にやることは接続なので、その人のトップは管理の画面のほうがよい
